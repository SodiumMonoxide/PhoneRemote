# Windows 电脑遥控指南

适用 Windows 2.5.0。两台电脑均更新至 2.5.0，分别使用被控端和控制端。Android 2.3.0 可继续连接，不需要重装。旧 Windows 被控端不支持新增的按下/松开键盘协议。

## 第一次连接

1. 在需要被操作的电脑上启动 PhoneRemote。选择「局域网」或「Tailscale」，选择正确网卡地址，点「启动连接」。
2. 点「复制连接信息」，将两行内容传到用于操作的电脑：第一行是完整 HTTPS 地址，第二行是 SHA-256 证书指纹。
3. 在控制电脑上运行 PhoneRemote，点主界面或托盘菜单中的「控制另一台电脑」。只使用控制功能时，无须启动本机被控服务。
4. 选择相同连接模式，点「粘贴连接信息」，与被控电脑核对地址和指纹。也可手动填写。
5. 输入被控端显示的 8 位配对码，记住后连接。配对码 5 分钟有效；过期后在被控电脑生成新码。

如果已经配对手机：先断开当前遥控会话，再点「生成新码」添加电脑。原有手机配对仍然保留。请勿为添加电脑点击「忘记所有设备」。每种模式最多记住 16 台设备。

## 局域网与办公室连接

在家同一可信局域网可以直接连接；网线和 Wi-Fi 接同一路由器也可以。访客网络或设备隔离可能阻止连接。

不同 Wi-Fi 时，两台电脑都安装并登录 Tailscale，加入同一个 Tailscale 网络。被控端启动 Tailscale 模式，控制端选择 Tailscale 并使用被控电脑的 Tailscale 地址。访问规则须允许控制端访问被控端 TCP 8443，不需要公网端口转发。

两种模式分别首次配对，之后选择对应模式重连即可；修改地址或指纹时需要重新核对并配对。复制的信息使用 IPv4 地址和端口，支持私有局域网地址与 Tailscale 的 IPv4 地址。

## 如何操作

画面按比例显示，黑边不对应远程桌面。进入键鼠控制后，可以直接用鼠标移动、单击、双击、右键、拖动和滚动，用键盘按下和松开普通键、方向键、Tab、Esc、功能键及修饰键组合。键盘只在当前遥控画面获得焦点时接管，不记录键盘日志。文字的键盘布局与输入法由被控电脑决定；也可使用下文的本机文本粘贴。

顶部默认只显示折叠的工具栏，展开后可选择进入/退出键鼠控制、全屏、准备粘贴本机文本和断开连接。按住工具栏拖动手柄可以移动位置，工具栏会限制在画面范围内。

选择「全屏」或按 **Ctrl+Alt+Enter** 后，被控画面占满整个窗口区域，原有连接表单及底部文字区不再挤占画面。不同屏幕比例仍会保留黑边以避免拉伸。普通 F11 和 Esc 在键鼠控制中交给被控电脑。

选择 **「退出键鼠控制」或按 Ctrl+Alt+F12**，会释放按键及鼠标，同时退出全屏、恢复普通窗口；连接和画面继续保留。需要继续操作时，从工具栏明确恢复键鼠控制。切换到其他本机应用、失去焦点、连接中断时，也会释放已按住的输入。

系统安全桌面及 Ctrl+Alt+Delete 不会被模拟或绕过。当前显示主显示器，画面为周期 JPEG 截图，适用于日常桌面操作；暂不支持文件传输、音频和多显示器切换。

## 从主控电脑粘贴文字

1. 展开顶部工具栏，选择「准备粘贴本机文本」。应用退出键鼠控制并恢复普通窗口，打开文字预览。
2. 可以切到本机其他应用复制需要的内容，再回到预览中读取剪贴板，或直接粘贴和编辑文字。
3. 核对预览和被控电脑当前输入位置，点发送才会将文本发到被控电脑。取消不会发送。
4. 长文本会按完整 Unicode 字符分段，按顺序发送；发送失败不会自动重试，避免重复输入。发送结束后手动恢复键鼠控制。

直接按 Ctrl+V 仍使用被控电脑自己的剪贴板。程序不会在后台自动读取、上传或同步主控电脑的剪贴板。

同一时刻只有一个有效遥控会话。另一设备正在操作时，先从当前设备断开，或者在被控电脑点「断开设备」，再连接。

## 关闭与保存

关闭控制窗口会断开此次控制并保留已记住的连接。关闭被控端主界面时选择「后台运行」，服务继续运行，托盘显示状态。「退出应用」同时结束控制端和被控端。

配对记录加密保存在当前 Windows 用户的 `%LOCALAPPDATA%\PhoneRemote\windows-client.dpapi`，不要公开或随安装包分发。不保存配对码。主机原有手机配对和证书与控制端记录独立。

## 只有一台电脑时

可以把本机被控端复制的连接信息粘贴到本机控制窗口，完成独立的新设备配对、画面查看、断开与重连。连接本机地址会强制只读，避免鼠标或键盘输入在同一桌面递归触发。画面里显示自身窗口造成的镜面效果属于本机预览现象。

此版本进行了隔离的 HTTPS 连接、证书拒绝、配对保留、输入事件和窗口生命周期测试。尚未进行两台实体 Windows 电脑的实际遥控，也未验证真实双机跨 Wi-Fi 环境。

取得第二台电脑后，依次验证同网画面与文字输入、鼠标单双击与拖动、缩放与全屏、断网重连、Tailscale 跨 Wi-Fi，以及切回原手机配对。测试过程中保持被控电脑可随时本地断开连接。

## 连接不上的排查

先确认被控电脑开机联网、桌面未锁定、对应服务已启动，再检查连接模式、完整地址和指纹。检查被控电脑防火墙的程序路径及 TCP 8443 入站规则；控制电脑无需为控制功能开放入站端口。

指纹不匹配时，从被控电脑重新复制并核对，不要跳过校验。已保存的授权失效时用新的配对码连接。锁屏、休眠、UAC 安全桌面和高权限程序不保证能操作；应用不会绕过这些系统保护。
