# 使用指南

适用版本：Windows 2.3.0、Android 2.3.0。安卓 2.2.0 连接协议仍兼容。

## 安装与升级

1. 完整解压 Windows 便携包，放在固定目录，双击 `PhoneRemote.exe`。升级前从旧版应用中退出，后台运行的新版可在托盘右键菜单中选择「退出应用」。
2. 用同一签名的 Android APK 覆盖安装。请保留手机应用数据和电脑的 `%LOCALAPPDATA%\PhoneRemote` 文件夹，这样可以沿用已有配对和证书。
3. 两端均有内置「使用指南」，可以离线查看。电脑启动后，分别启动需要的连接方式。

## 同一局域网

手机和电脑连接同一个可信 Wi-Fi，电脑用网线接入同一路由器也可以。在电脑端选择「局域网」，确认地址对应正确网卡，再点「启动连接」。访客网络或路由器设备隔离可能阻止直接连接。

## 异地、不同 Wi-Fi 或移动数据

在电脑和手机分别安装 Tailscale，登录并加入同一个 Tailscale 网络。确认两台设备在线，然后在电脑端选择「Tailscale」地址并启动连接。看不到地址时，先确认电脑 Tailscale 已连接，再点「刷新」。

Tailscale 的访问规则应允许手机访问电脑的 TCP 8443。无需把路由器端口映射到公网。手机可以使用另一个 Wi-Fi 或移动数据，只要 Tailscale 连接正常。

## 首次配对

1. 在电脑选好连接方式并启动，点「复制连接信息」。结果是两行：完整 HTTPS 地址和完整证书 SHA-256 指纹。
2. 将这两行传到手机并复制。在手机点该方式的「设置」，再点「粘贴连接信息」。也可以手动填写，地址须保留 `https://` 和端口 `8443`。
3. 核对地址与指纹后点「保存并连接」，输入电脑同一方式的 8 位配对码。配对码有效 5 分钟，过期后在电脑点「生成新码」。
4. 勾选「记住这部手机，之后直接连接」，再点「连接」。出现电脑画面后即可操作。

指纹必须从自己电脑的界面取得。不要用聊天示例或别人的指纹替代。

## 在家和办公室切换

先分别完成局域网和 Tailscale 的首次配对。在电脑顶部两个页面分别点「启动连接」，保持两种服务都在运行。手机在家时点顶部「局域网」，在外时确保 Tailscale 在线，再点顶部「Tailscale」。

手机为两种方式分别保存地址、指纹和配对。切换只更换本次控制方式，另一份配对会保留。应用重开时恢复上次选择，同一时刻只有一个有效控制会话。

## 关闭操作界面，继续后台运行

点击 Windows 窗口关闭按钮，选择「后台运行」。操作界面隐藏，已启动的服务继续运行，当前遥控连接保持。

右下角通知区域显示应用图标。悬停或右键可查看局域网和 Tailscale 的状态，双击可恢复界面。图标可能在「显示隐藏的图标」菜单中，可以将它拖到任务栏通知区域。再次运行 `PhoneRemote.exe` 也会恢复已经运行的窗口。

后台运行不会阻止 Windows 休眠、注销或关机，也不会自动加入开机启动。电脑需要开机、联网、桌面可用。

## 结束控制和退出

- **断开手机**：结束所选方式的当前会话，保留配对，手机之后可重连。
- **忘记手机**：撤销所选方式的配对，下次需重新配对。更换手机时分别撤销需要更新的两种配对。
- **停止连接**：只停止当前页面的服务，另一种已启动的服务继续运行。
- **退出应用**：停止两种服务并移除托盘图标，已保存的配对保留。可从窗口关闭选择或托盘菜单执行。

## 连接不上的排查顺序

1. 确认电脑开机、联网、用户桌面可用，所需连接服务正在运行。后台时可查看托盘状态。
2. 确认手机选择的连接方式、完整地址和证书指纹与电脑一致。
3. 局域网模式确认两端同网，没有访客隔离。Tailscale 模式确认两端在线，网络访问规则允许 TCP 8443。
4. 检查 Windows 防火墙是否允许当前 `PhoneRemote.exe` 路径和所需接口上的入站连接。更换程序目录可能使旧路径规则失效。
5. 已配对但无法恢复时，确认没有清除应用数据、变更电脑地址或证书。手机 Tailscale 地址更换时也可能需要重新配对。
6. 证书或配对存储损坏时，先退出应用并备份 `%LOCALAPPDATA%\PhoneRemote`，再由了解情况的人处理和重新配对。不要先删除文件。

电脑锁屏、休眠和 UAC 安全桌面会中断普通桌面的可控状态。应用不会绕过 Windows 登录或管理员确认。

## 浏览器备用连接

在可信局域网中，也可从手机浏览器访问电脑面板中的完整 HTTPS 地址。浏览器可能提示自签名证书，请在证书详情核对 SHA-256 指纹。无法查看指纹时使用安卓应用。
