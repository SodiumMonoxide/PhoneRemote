# Mac 与 Windows 远程控制

两台电脑各运行自己的 PhoneRemote。先决定要共享哪一台的主屏幕，再在另一台电脑输入连接信息。Mac 可以担任任一角色，也可以连接另一台 Mac。

| 被控电脑 | 启动共享 | 在控制电脑上连接 |
| --- | --- | --- |
| Windows | 选择局域网或 Tailscale 地址，点「启动连接」「复制连接信息」 | Mac 首页点「粘贴连接信息」「前往配对」 |
| Mac | 点「打开被控服务」，在终端输入地址编号，输入 `c` 复制连接信息 | Windows 点「控制 Windows 或 Mac」，选对应网络模式并粘贴 |
| Mac | 同上 | 另一台 Mac 在首页粘贴信息并前往配对 |

## 安装和首次授权

Mac 应用最低部署版本为 macOS 14。在「关于本机」查看芯片类型。Apple M 系列选择 Apple Silicon 包，Intel 处理器选择 Intel 包。解压后把 `PhoneRemote.app` 放入「应用程序」并打开。两个包都自带运行时。当前 Mac 应用为本地签名构建，尚未经过 Apple 公证。Windows 用户解压便携包并运行 `PhoneRemote.exe`。

如果首次打开时系统提示开发者身份无法验证，可对照交付的 SHA-256 确认文件来源，再按 Apple 的说明为该应用单独确认打开。[Apple 的首次打开说明](https://support.apple.com/zh-cn/102445)

仅用 Mac 控制另一台电脑时，直接从首页前往配对。让其他电脑控制这台 Mac 时，首次启动被控服务会申请「屏幕录制」和「辅助功能」权限。在「系统设置 → 隐私与安全性」按系统列出的应用名称授权，再重新打开被控服务。共享期间保持被控电脑已解锁、服务终端打开。

## 配对和操作

1. 同一局域网选择能互通的局域网地址。跨网络时两端先加入同一 Tailscale 网络，被控端选择其 Tailscale 地址。
2. 通过可信渠道把 HTTPS 地址和完整的 SHA-256 指纹交给控制端。确认与被控端一致，再输入被控端显示的 8 位配对码，有效期五分钟。
3. 在 Mac 控制端点击远程画面后，直接左击、双击、右击、拖动和滚动。键盘可输入文字和常用按键，Esc 返回操作面板；需要把 Esc 发给远程电脑时点「按键与快捷键」中的 Esc。中文输入或粘贴长文本使用「输入文字」，每次最多 256 个 UTF-16 单元。
4. 用 Windows 实体键盘操作 Mac 时，Windows 徽标键对应 Command，Alt 对应 Option，Ctrl 对应 Control。例如用 Windows 徽标键加 C 可在远程 Mac 中复制。Windows 控制窗口保留 Ctrl+Alt+F12 退出键鼠控制及 Ctrl+Alt+Enter 切换全屏。
5. Mac 控制端用一次性配对码建立会话。再次连接时，在被控 Windows 点「生成新码」，在被控 Mac 的服务终端输入 `n`。Windows 控制端可以勾选记住设备。

## 结束共享

控制端点「断开」。Mac 被控服务的终端里，`d` 断开当前控制者，`n` 生成新码，`f` 撤销当前网络模式已记住的设备，`q` 停止服务。命令输入后按回车。Mac 被控服务在独立终端运行，关闭控制端窗口后仍可在该终端停止共享。

如果没有画面，先在被控 Mac 本机确认已登录、主屏幕已唤醒，并检查屏幕录制权限。有画面却无法操作时检查辅助功能权限。若证书校验失败，重新从被控端复制两行信息，同时检查两端系统时间。
